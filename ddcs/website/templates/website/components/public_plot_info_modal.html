Hinweis zur Datenquelle

Diese Grafiken basieren auf einer kuratierten Liste offizieller Partei-Accounts auf TikTok. Die Daten werden über die offizielle TikTok Research API erhoben.

Aufgrund technischer Instabilitäten der API können die Daten unvollständig sein oder zeitweise nicht abgerufen werden.

Mehr Informationen zur Methodik finden Sie auf unserer Methoden-Seite.
